# Музыка в машину

Одна HTML-страница, которая показывает на экране автомобиля (или любом браузере) то, что сейчас играет в вашем Spotify: большую обложку, вращающийся винил, текст песни по словам (караоке) и красивый переход Mix, когда экран делится между двумя треками.

Страница ничего не проигрывает сама. Музыка играет с телефона (Bluetooth, Spotify Connect), а страница только отображает текущий трек. Поэтому она работает почти в любом браузере.

Серверной части нет: токены Spotify хранятся только в браузере (localStorage).

## Что нужно

- Аккаунт Spotify Premium.
- Бесплатный аккаунт GitHub (для размещения страницы).
- Браузер в машине или на телефоне, открытый в горизонтальном режиме.

## Установка за 10 минут

### 1. Разместите страницу на GitHub Pages

1. Создайте репозиторий на github.com, например `car-music`.
2. Загрузите в него файл `index.html` (Add file → Upload files).
3. В репозитории откройте Settings → Pages → Build and deployment. Выберите Deploy from a branch, ветку `main`, папку `/ (root)`. Сохраните.
4. Через минуту страница откроется по адресу вида `https://ВАШ-ЛОГИН.github.io/car-music/`.

### 2. Создайте приложение Spotify

1. Откройте [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и нажмите Create app.
2. В поле Redirect URI вставьте адрес вашей страницы из шага 1, точно так же, включая `/` в конце. Страница сама показывает нужный адрес на экране входа, его можно скопировать кнопкой.
3. Отметьте Web API и сохраните приложение.
4. В настройках приложения скопируйте Client ID.
5. Откройте User Management и добавьте email своего Spotify-аккаунта (и аккаунтов друзей, если нужно).

### 3. Войдите

1. Откройте страницу, вставьте Client ID и нажмите «Войти в Spotify».
2. После входа включите музыку в Spotify на телефоне. Экран заработает сам.

Отправьте себе ссылку на страницу в заметки или мессенджер и откройте её в браузере машины.

## Как это работает

- Текущий трек запрашивается у Spotify Web API раз в 4 секунды, прогресс между запросами считается локально.
- Тексты с таймингами берутся из открытой базы [LRCLIB](https://lrclib.net). Если текста для трека нет, показывается обложка.
- Цвета фона берутся из обложки.
- Mix: за несколько секунд до конца трека страница узнаёт следующий трек из очереди и показывает переход. Если очередь недоступна, переход запускается при смене трека.

## Кнопки

- **Караоке**: показывает или прячет текст. Без текста обложка стоит по центру.
- **Винил**: пластинка за обложкой.
- **Mix**: включает или отключает переход между треками.
- **− / +**: сдвиг текста на 0,5 секунды, если он идёт не в такт.
- **Выйти**: удаляет токены из браузера.

## Ограничения

- В Development Mode владельцу приложения нужен активный Spotify Premium; одно приложение может иметь до пяти авторизованных пользователей. В июле 2026 Spotify увеличил лимит до 25 Client ID на аккаунт разработчика, но квота запросов общая для его приложений. Проверьте [режимы квот](https://developer.spotify.com/documentation/web-api/concepts/quota-modes) и [обновление лимитов Spotify от июля 2026](https://developer.spotify.com/blog/2026-07-23-web-api-quota-updates).
- Старые браузеры машин могут не поддерживать современные возможности CSS. В этом случае анимации упрощаются или не работают.
- Для работы нужен HTTPS.

## Конфиденциальность

Страница обращается только к Spotify (api.spotify.com, accounts.spotify.com) и LRCLIB (lrclib.net). Своего сервера, аналитики и сторонних скриптов нет.

## Отказ от ответственности

Проект независимый и не связан со Spotify AB. Spotify является товарным знаком их владельцев. Тексты песен принадлежат правообладателям и загружаются из LRCLIB только для отображения. Используйте проект в соответствии с условиями Spotify для разработчиков.
